# 🚀 Cosmic Joke Generator

Welcome to the Cosmic Joke Generator - a fun, interactive website where the universe meets comedy!

## 🌟 Features

- ✨ **20+ Cosmic Jokes** - Jokes spanning from space puns to science humor
- 🎨 **Psychedelic Animations** - Smooth gradient transitions and bouncing effects
- 📊 **Real-time Statistics** - Track jokes generated and laughter levels
- 🎯 **Responsive Design** - Works perfectly on desktop and mobile devices
- ⚡ **Instant Loading** - No dependencies, pure HTML/CSS/JavaScript

## 🎮 How to Use

1. Open `index.html` in your web browser
2. Click the "✨ Generate Cosmic Joke ✨" button
3. Watch your jokes and laughter meter increase!
4. Share the cosmic joy with friends
